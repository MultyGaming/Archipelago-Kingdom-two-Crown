# Third-party components

- **BepInEx** — LGPL-2.1; official base build 6.0.0-be.753, Unity IL2CPP, Windows x64, must be installed separately. `PatchAK2C.zip` redistributes BepInEx `core` assemblies and the optional BepInEx Configuration Manager patcher taken from the tested modpack setup. Official source: https://github.com/BepInEx/BepInEx.
- **Archipelago.MultiClient.Net** and **APNewtonsoft.Json** — runtime dependencies included alongside the mod plugin. Their upstream licensing terms remain applicable; see the Archipelago project and the package/source distribution used to build this mod.
- **Archipelago** — the APWorld source and `.apworld` package are for the Archipelago 0.6.8 API and retain the project’s own license terms.

No game files or complete standalone BepInEx installation are redistributed here. `PatchAK2C.zip` contains BepInEx components; consult the BepInEx source and license above for their terms.
